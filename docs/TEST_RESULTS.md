## 复现

```sh
python -m pytest
python scripts/release_check.py
python scripts/check_privacy.py --strict
```

隐私检查只输出类别与位置，不回显命中值。默认只检查 Git 可纳入版本的工作文件；额外使用 `--history` 审查可达历史文本，不修改历史或远端。脚本不执行 OCR，本次另用系统本地 OCR 人工触发检查全部 7 张公开图片，识别文本未发送外部服务，报告仅含位置、字符数与命中类别。本次新增提交使用 GitHub noreply 邮箱；不改写已有作者元数据。OCR 可能漏识别，规则也不覆盖所有秘密格式或其他人的副本，因此不能据此保证绝对无泄露。
