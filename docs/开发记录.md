## 一、本地做了什么（功能清单）

### 1. 内容生成
- **双 LLM 后端 + 模型切换**：DeepSeek（云端）/ 本地 Ollama（qwen2.5:3b、7b，免费）；未配 Key 自动探测本地 Ollama，都没有则走离线模板，永不报错
- **多人格系统**：`config/personas.yaml` 人格库（6 个人格：小鹿学姐/干货知识风/种草测评风/旅行探店风/情感共鸣风/职场进阶风），每人格含 语气/习惯/开头风格/互动引导/标题风格/适用主题/示例，生成时编译成写作指令块；**按主题自动推荐人格**（可手动切换/一键回推荐）
- **提示词资产化**：`config/prompts.yaml` 热更新，改文案不动代码
- **RAG 知识库**：`knowledge/*.md`（front-matter 结构化：topic/style/keywords），中文 bigram 主题加权检索 + 相关性门槛防跑题
- **合规引擎**：广告法绝对化用语/医疗金融承诺/导流话术，发布前自动拦截（实测拦截过「万能」）
- **内容清洗**：去 Markdown 标记（`**`）、去组合 emoji（`①⃣`）、限 emoji 数量、去「段一」标签

### 2. 真实发布（重点攻坚）
- **上传图文模式**：小红书新版发布页默认「上传视频」，需切「上传图文」并先传 ≥1 张图，编辑器才出现
- **闭合 Shadow DOM 发布按钮**：`<xhs-publish-btn>` 是闭合 shadow 自定义组件，选择器/无障碍树都拿不到 → 用 PIL 截图像素定位红色按钮坐标 → 按宿主相对位置点击
- **真实成功判定**：以 URL 出现 `published=true` / 成功提示 / 抓取真实链接为准，拿不到证据就报「未确认」，**绝不假装成功**
- **扫码风控处理**：小红书「新设备登录」要求 App 扫码验证 → 有头模式自动等待扫码（最长 120s），扫码完成后自动继续发布；发布成功后保存登录态（含信任标记），降低下次触发频率
- **商用管控**：限流（发布/分钟）、幂等（publish_log 去重）、人工审批、审计留痕、登录态隔离
- **定时调度**：`content_bank/*.json` 到期自动发布 + `publish_log.json` 留痕

### 3. 多模态 · 封面生成
- 本地海报 5 种风格（premium 高级暗调 / minimal 留白极简 / gradient / split / card），同主题风格一致
- **描述驱动**：用户描述封面（如「粉色渐变 可爱风」）→ 自动解析风格/配色生成；AI 后端则直接把描述当图生图提示词
- **AI 背景预留**：配 SiliconFlow Key 后自动 AI 背景 + 标题叠加，无 Key 回退海报

### 4. 联网增强
- 生成前抓热点/参考（Bing 免 Key / 博查 / Tavily），**相关性过滤**（结果须含主题片段才注入），失败自动跳过

### 5. 可视化工作台（Streamlit 5 页）
生成编辑 / 内容库定时 / 知识库 / 设置（后端·模型·人格·联网·封面）/ 状态日志；未配 Key 给清晰提示

### 6. 工程与运维
- 52 项 pytest 全绿；安全校验脚本 `scripts/check_secrets.py` + git pre-commit 钩子
- CLI：generate / publish / schedule / login / notes / probe / debug-selectors / personas / eval
- 知识图谱（Markdown + Word）、README、秋招材料

## 二、遇到的问题 & 怎么解决

| # | 问题 | 根因 | 解决 |
|---|---|---|---|
| 1 | 早期「发布成功」是假成功 | 成功判定太松（误匹配提示文字），且返回占位链接 | 改为必须拿到证据（`published=true`/成功提示/真实链接）才算成功，否则报「未确认」并留现场截图 |
| 2 | 长文编辑器**根本没有发布按钮** | 小红书网页版长文是编辑器，发布入口在别处 | 改走「上传图文」模式（标准图文笔记才有发布按钮） |
| 3 | 发布按钮点不到（选择器/无障碍树都找不到） | `<xhs-publish-btn>` 是**闭合 shadow DOM** 自定义组件 | 截图 + PIL 像素定位红色按钮 → 按宿主相对坐标点击（0.62×宽, 0.5×高） |
| 4 | 图片上传失败（找不到文件输入框） | XHS 文件框是隐藏元素，`_find` 要求 visible | 改 `state=attached` + `set_input_files`（对隐藏元素有效） |
| 5 | 发布弹「扫码验证」后被中断 | 新设备风控，headless 无法扫码，且代码立即结束流程 | 有头模式**等待用户扫码（120s）**，扫完自动继续；无头直接明确提示 |
| 6 | 每次发布都提示「新设备」 | Playwright 每次全新指纹，storage_state 只有 cookie | 发布成功后回写登录态（含信任标记），降低触发频率 |
| 7 | 状态页崩溃：`numpy.dtype size changed` | pandas 2.0.3 与 numpy 2.4 二进制不兼容 | 状态页改无 pandas 渲染（markdown 表格）+ `pip install -U pandas`（3.0.5） |
| 8 | Streamlit 报 `cannot modify session_state after widget instantiated` | 在 selectbox 之后改它的 state | 按钮改用 `on_click` 回调 |
| 9 | 本地 3b 输出垃圾（`①⃣`、emoji 泛滥、段标签） | 小模型通病 | 字符清洗（去变体符/带圈数字/段标签/限 emoji）+ 提示词约束 + 升级 7b |
| 10 | 标题被人格示例带偏（照抄示例句） | 标题提示词注入了完整人格示例 | 标题改用「精简人格」（只给语气+标题风格） |
| 11 | 必应检索结果跑题（搜「秋招穿搭」返回「秋」字典） | 无相关性门槛 | 主题片段匹配过滤，无关结果不注入 |
| 12 | CMD 里 `cd D:\...` 不生效 | CMD 需 `/d` 才切盘 | `cd /d`；并做了双击启动脚本 |
| 13 | 改了代码界面还报旧错误 | Streamlit 热重载不重载已 import 模块 | 重启 Streamlit |
| 14 | 爬虫/自动化被平台风控 | 自动化高频访问 | 控制频率（限流）、有头模式+扫码、信任标记持久化 |
