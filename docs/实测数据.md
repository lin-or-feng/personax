# PersonaX 实测数据

> 实测时间：2026-08-30 ｜ 环境：本机 Ollama `qwen2.5:7b`（GPU：NVIDIA RTX 4060 Ti 8GB）
> 方法：纯本地、免费、无联网，5 次真实生成 + 5 次干跑发布；数据由用量埋点自动落盘 `logs/usage.jsonl`，聚合后存档于 `docs/实测数据.json`。

---

## 1. 单篇端到端耗时（主题 → 完整草稿）

| 指标 | 数值 |
|---|---|
| 平均耗时 | **6871 ms（≈6.9 秒）** |
| 最快 / 最慢 | 6276 ms / 7638 ms |
| 样本数 | 5 次实测 |
| 每篇 LLM 调用次数 | 3 次（标题 → 正文 → 标签/封面文案） |

> 说明：以上为「生成」段耗时。真实发布另需浏览器自动化（打开创作台 → 上传图文 → 点发布），实测约 **30~45 秒/篇**（受小红书页面加载影响，属 estimate，未计入上表）。

## 2. Token 消耗（每篇）

| 指标 | 数值 |
|---|---|
| prompt 平均 | **916 token**（范围 724~1053） |
| completion 平均 | **237 token**（范围 213~289） |
| 每篇合计 | **≈1153 token** |

## 3. 发布成功率

| 类型 | 结果 |
|---|---|
| 干跑发布（链路可用性） | **5 / 5 = 100%** |
| 真实发布 | **3 次成功**（`publish_log.json` 留痕；成功依据 = 页面 URL `published=true`，非假成功） |

## 4. 知识库规模

- **3 篇范例 / 358 汉字 / 9 段落**（秋招穿搭、租房避坑、考研英语）

## 5. 账号状态与恢复

- 账号**未封禁**；历史遇过 1 次风控（无头模式缺设备信息 → 发布失败）。
- **恢复方式**：补设备信息 + 切有头模式（可扫码验证）→ 发布恢复正常。
